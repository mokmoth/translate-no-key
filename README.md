# TranslateNoKey

TranslateNoKey 是一个本地优先的配置文本辅助脱敏与还原工具。它在当前浏览器页面内处理 JSON、YAML、ENV、TOML、普通文本和 URL 查询参数，不需要后端服务，也不发起网络请求。

## 使用

1. 用浏览器打开 `index.html`，或在本目录启动任意静态文件服务器。
2. 粘贴配置并点击“脱敏”。
3. 人工复核输出，确认所有敏感值都已替换，再交给第三方或 AI。
4. 将修改后的占位符文本粘贴回来并点击“还原”。

映射表只保存在当前页面内存中。需要跨会话还原时可以导出映射 JSON，并在可信环境中重新导入。

## 安全边界

- 检测是 **best-effort**，不是密钥泄漏防护的形式化保证。未知格式、拆分值、编码值或新型凭据可能漏检，输出必须人工复核。
- 映射 JSON 包含全部原始敏感值的**明文**。不要上传、提交到 Git、发送给 AI 或保存在不受信任的位置。
- 刷新/关闭页面或点击“清空映射”会丢失未导出的映射，之后无法自动还原对应占位符。
- 页面中的“查看映射”会显示原始值，只应在可信设备和无旁观者环境中使用。
- 工具不会把输入保存到浏览器存储，但浏览器扩展、剪贴板管理器、截图工具和托管环境不在本项目的控制范围内。

更多说明见 [PRIVACY.md](PRIVACY.md) 与 [SECURITY.md](SECURITY.md)。

## 本地检查

需要 Node.js 18 或更新版本，无需安装依赖：

```sh
npm test
npm run check
```

测试使用合成值，覆盖 JSON、YAML、ENV、TOML、普通文本、URL，以及精确占位符与通用遮罩混用的还原场景。
